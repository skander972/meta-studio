🎨 How Discord Uses Theme Color

Discord reads the <meta name="theme-color"> tag and renders it as the colored vertical stripe on the left border of the embed box.

🤖 Discord Cache Invalidation Tip

Discord aggressively caches link previews. To test changes, append a query parameter like ?v=2 to force Discord's scraper bot to re-fetch your metadata.
